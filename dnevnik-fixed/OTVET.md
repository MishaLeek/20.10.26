# Задание «Найди и исправь ошибки» — Электронный дневник (Flask)

Исправленный файл: `app.py`. Всего найдено 3 ошибки.

## Ошибка 1. Старые и чужие средние баллы (кэш)

- **Где была:** строка 113, декоратор `@lru_cache(maxsize=None)` над функцией `subject_average`.
- **Когда неправильно:** поставить оценку по предмету, открыть дневник, поставить ещё одну оценку. Средний балл и итог остаются прежними. Также второй пользователь видит средний балл первого, потому что кэш хранит результат по `subject_id`, а `user_id` в ключ кэша не входит.
- **Почему:** `lru_cache` запоминает результат функции для того же аргумента. Функция берёт `user_id` из сессии, но кэш этого не знает, поэтому возвращает старое значение.
- **Исправление:** убрал декоратор `@lru_cache` и ставший ненужным импорт `lru_cache`.

## Ошибка 2. Неверное округление итога

- **Где была:** строка 125, `return round(average)` в функции `final_grade`.
- **Когда неправильно:** средний балл 2,50 даёт итог 2 (должно быть 3), 4,50 даёт 4 (должно быть 5). Для 3,50 результат верный, поэтому ошибка видна не всегда.
- **Почему:** функция `round()` в Python округляет «до ближайшего чётного» (банковское округление), а по школьным правилам 0,5 и больше округляется вверх.
- **Исправление:** `return math.floor(average + 0.5)` (и `import math`).

## Ошибка 3. Неправильная сортировка и статусы заданий (даты как текст)

- **Где была:** строки 244, 249 и 251: `ORDER BY done, deadline, homework.id` и сравнения `hw["deadline"] < today_text`, `hw["deadline"] == today_text`.
- **Когда неправильно:** срок хранится как текст `ДД.ММ.ГГГГ`, поэтому сравнение идёт по символам, начиная с дня. Задание `05.01.2027` оказывается раньше `23.10.2026`, а задание со сроком `01.11.2026` может получить статус «Просрочено» только потому, что «01» меньше «20» (день сегодняшней даты).
- **Почему:** строки сравниваются посимвольно, а не как даты.
- **Исправление:** задания выбираются без сортировки в SQL, затем сортируются в Python по ключу `(done, parse_date(deadline), id)`, а статус определяется сравнением настоящих дат (`deadline < today`, `deadline == today`).
